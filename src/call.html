mut3d

Private video calls and chat for up to 4 people. No account, no phone number, no app. Nothing is stored.


You were invited. Ready?


How is this private?

Video, voice, chat and files go straight between the people in the call, encrypted. The call's secret key is the part of the link after the #, which your browser never sends to any server. Anyone with the full link can join, so share it only with people you trust. There is no server that stores anything. A small public introduction server helps browsers find each other; it sees that a connection is being made, not what is said. The encryption has not been independently audited, so do not rely on it for life-or-death secrecy. Open source: github.com/arbonomous/private-room
