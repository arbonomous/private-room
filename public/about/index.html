Free. No account. No phone number. Nothing to install.

How it works

  1. Make a room. One tap. You get a link.
  2. Send the link to the people you want (share sheet, QR code or copy).
  3. Let them in. Each person knocks and you approve. Lock the room when everyone is here.

What you get

  • Video and voice calls, text chat, file sharing, up to 4 people.
  • Calls go straight between devices and are encrypted in the browser. The server only helps people find each other.
  • Nothing is stored: no accounts, no call history, no recordings.
  • Optional privacy tools: voice disguise, face mask, blur background only, dark or light theme.
  • An "End room for everyone" button that wipes chat and files from every open tab.

Honest limits

  • The cryptography has not been independently audited. This is a small project, not a replacement for Signal or any audited tool. Do not use it where your safety depends on it.
  • Anyone with the full link can knock. Share it only over a channel you trust.
  • People in a call can see each other's network addresses, because devices connect directly. A small free relay is a fallback and may run out.
  • Host approval and the end-room button run in each person's browser. Someone with modified code could ignore them, and anyone can screenshot or record.
  • Tested in lab browsers, not on every phone yet. Older phones may run warm with the face mask or blur on.

The full list is in the README. The code is open so you can check what it does.
